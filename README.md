## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Visit `http://localhost:3000` to view the website.

### 3. Production Build
```bash
npm run build
```
Generates production-optimized static files in `/dist`.

---

## Netlify Deployment

1. Push this repository to GitHub.
2. In Netlify, click **Add new site** > **Import an existing project**.
3. Select your repository. Netlify will automatically detect:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
4. Deploy the site. The included `netlify.toml` handles single-page app redirects and cache policies automatically.
5. Inquiries submitted through the contact form will automatically appear in your **Netlify Forms** dashboard.
